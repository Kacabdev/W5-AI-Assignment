# Garasho Dhaqan 🇸🇴

**Garasho Dhaqan – Safarka Aqoonta Soomaaliyeed** waa ciyaar su'aalo iyo jawaabo ah oo lagu sahminayo dhaqanka, hiddaha iyo suugaanta Soomaaliyeed.

Mashruucan waxaa loo sameeyay in lagu barto laguna tababarto JavaScript fundamentals iyadoo la dhisayo game shaqaynaya.

## Waxyaabaha ku jira

- 4 qaybood: Cuntooyinka, Dhaqan iyo Hiddo, Nolosha Reer Miyiga, Af iyo Suugaan.
- 5 su'aalood qayb kasta (20 su'aalood guud ahaan).
- Su'aalaha qayb kasta si random ah ayaa loo kala hormariyaa.
- 10 dhibcood jawaab kasta oo sax ah.
- 5 dhibcood oo bonus ah marka la gaaro 3 jawaabood oo sax ah oo xiriir ah.
- Jawaabaha saxda iyo khaldan waa la tirinayaa.
- Natiijo qayb kasta iyo qiimayn guud.
- Dib ayaa loo bilaabi karaa ciyaarta.

## Teknoolojiyada

- HTML5
- CSS3
- Vanilla JavaScript (framework la'aan)

## Sida loo socodsiiyo

1. Soo dejiso ama clone-garee repository-ga.
2. Fur folder-ka `garasho-dhaqan`.
3. Fur `index.html` browser-kaaga.

Waxaad sidoo kale adeegsan kartaa **VS Code Live Server** si aad ugu furto browser-ka.

## Qaab-dhismeedka faylasha

```text
garasho-dhaqan/
├── index.html
├── style.css
├── app.js
└── README.md
```

## JavaScript concepts-ka lagu tababaranayo

| Concept | Isticmaalka mashruuca |
|---|---|
| Variables | Dhibcaha, streak iyo su'aasha hadda taagan |
| Arrays | Liiska categories, su'aalaha iyo jawaabaha |
| Objects | Xogta category kasta, su'aal kasta iyo game state |
| If / else | Hubinta jawaabta, bonus-ka iyo qiimaynta |
| Functions | Shaqooyinka kala duwan ee game-ka |
| Array methods | `forEach()`, `find()`, `includes()` |
| Array operations | `push()`, spread syntax iyo destructuring |
| Math.random() | Kala-habaynta su'aalaha |
| DOM | Cusboonaysiinta waxa browser-ka ka muuqda |
| Events | Maamulka button clicks |

## Xeerarka dhibcaha

- Jawaab sax ah: **+10**
- Saddex jawaabood oo sax ah oo xiriir ah: **+5 bonus**
- Jawaab khaldan: streak-ku wuxuu ku noqdaa **0**
- Qayb kasta waxay leedahay **5 su'aalood**.

Bonus-ku wuxuu shaqeeyaa mar kasta oo streak-ku gaaro tiro 3 u qaybsanta (3, 6, 9, iwm). Dhibcaha ugu badan ee suurtagalka ahi waa 230.

## Xaddidaadaha noocan koowaad

- Natiijada ciyaarta laguma kaydiyo browser-ka.
- Ma jiro timer.
- Su'aalaha iyo jawaabuhu waa kuwo ku jira `app.js`.
- Internet ayaa loo baahan karaa si Google Fonts loo soo dejiyo; ciyaartu lafteedu offline ayay shaqayn kartaa marka faylasha la hayo.

## Ujeeddada waxbarasho

Mashruucan waxaa loogu talagalay in la fahmo sida arrays, objects, conditionals, functions iyo DOM events ay uga wada shaqeeyaan JavaScript application yar.
